# final-project

This is my final prohect for Boolean's Naster in Data Analytics Part Time (DAPT) course, class 29,

## Scenario

This project imagines an advisory consultant collaborating with a public lighting and road safety corporation.

The objective is that of identifying the Italian municipalities with the highest concentration of traffic accidents in order to address nighttime or low-visibility safety issues by strategically allocating grants for public lighting upgrades.

Data is automatically fetched from the ISTAT APIs, merged with SITUAS sources on population, and normalized into pro capite rates to ensure fair comparison across urban and rural settings alike.

Moreover, a forecasting of 2030 accident trends via an unsupervised learning model is employed to isolate the cities where the largest increase in accidents is expected, so that such municipalities can be the primary target of the public lighting improvement project.
